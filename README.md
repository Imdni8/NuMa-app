# Problem

New parents need help with tracking when they feed the child, burp them and when they pee and poop.

# Solution

NuMa lets new parents track activities related to taking care of a new child like feeding, burping, peeing, pooping, etc; so that they make better decisions. Additionally, NuMa lets new parents create any number of activities they choose. It also lets them upload and track their child's health records like vaccine certificates and prescriptions.

# Key differentiator

## Memories

NuMa has a library of key developmental milestones. Parents get notified about the important milestones based on the child's age so that they can capture these meories and at the same time track their child's key developmental milestones.

## Ease of use

NuMa's design is kept bare minimum to ensure the tracking isn't cumbersome

# Feature deep dive

This section describes the key features and interaction design of NuMa.

## Navigation

NuMa uses a Bottom nav bar with the following tabs:

1. Activities: for logging important child caring activities
2. Health records: For uploading health related documents like vaccines, prescriptions, etc.
3. Memories: For capturing child's key developmental milestones
4. Aai: AI coach where New parents can ask questions and get answers based on the data fed by them. They will be always reminded that this is not medical advice and here I can make mistakes.
5. User profile: for managing child's profile, app settings and subscription

## Activities

The activities section lays out all child caring activites a new parent is interested in tracking. Each activity is shown a tile with an icon, it's current Activities like feeding, burping, peeing and pooping are added by default. The user is able to do the following jobs on this screen:

1. Increment an activity: By tapping the tile
2. Create new activity: using the add button floating at the bottom right
3. Edit or delete existing activity: by long pressing the tile to get those options
4. View details of an event: by long pressing the tile to view the timeline of events of that day
5. View activity stats of the past: by changing the date
